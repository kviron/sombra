# Sombra

Первая версия для Windows x64 подключается к рабочему серверу Sombra. В группе владелец может выбрать «Пригласить участников», ввести email аккаунта Sombra и нажать «Пригласить». Группа появляется у этого аккаунта при ближайшем обновлении вместе с текстовыми и голосовыми каналами.

## Где находится код

Папка проекта на этом компьютере: `D:\media\Documents\Craft Anything\discord\app`.
Скопируйте этот путь в адресную строку Проводника и нажмите Enter.

- `ui` — интерфейс на React и TypeScript; точка входа — `ui/main.tsx`.
- `src` — код на Rust; запуск приложения — `src/main.rs`, серверная логика — `src/backend.rs`.
- `package.json` — команды запуска и сборки.

Эта версия сохранена в папке Craft Anything, указанной выше, а не в `D:\develop\Mines`.

## Как запустить

Откройте терминал в папке `app` и выполните:

```powershell
npm.cmd run tauri:dev
```

Если терминал открыт в корневой папке проекта `discord`, сначала выполните `cd app`.

Команда находится в `package.json`, в разделе `scripts` под именем `tauri:dev`.
В Windows используйте `npm.cmd`, если PowerShell блокирует неподписанный `npm.ps1`; в остальных оболочках подойдёт `npm run tauri:dev`.
Она запускает Tauri и Vite, открывая приложение отдельным окном с обновлением при изменении кода.
Для WebView2 автоматически создаётся отдельная папка профиля `mines-tauri-dev-profile` во временной папке Windows. Можно задать свой путь через `WEBVIEW2_USER_DATA_FOLDER`.
Короткая команда `npm.cmd start` запускает тот же режим.

`npm run dev` запускает только веб-версию. `npm run tauri -- dev` запускает Tauri напрямую, без настройки отдельного профиля WebView2.

## Проверка сборки

```powershell
npm.cmd run build
```

Для запуска Tauri нужны установленные Rust, средства сборки C++ для Windows и WebView2; зависимости JavaScript устанавливаются командой `npm install`.

## Сервер для нескольких пользователей

На сервере нужен только готовый файл бэкенда под systemd и HTTPS-прокси; приложение остаётся на компьютере пользователя. Сборка выполняется на своём компьютере через Docker, а Docker, Rust и Node.js на сервере не нужны. Пошаговая инструкция и контракт подключения клиента: [DEPLOY.md](DEPLOY.md). Текстовый чат и голосовые каналы; запись голосовых сообщений пока отсутствует.
