# Sombra 0.1.0 — первый выпуск для Windows x64

- [Приватный репозиторий и релиз v0.1.0](https://github.com/kviron/sombra/releases/tag/v0.1.0).
- [Установщик Windows x64](https://sombra.mi-nerva.ru/updates/0.1.0/Sombra_0.1.0_x64-setup.exe) и [манифест обновлений](https://sombra.mi-nerva.ru/updates/latest.json).
- Клиент подключается к `https://sombra.mi-nerva.ru/api`. Сессия хранится в Windows DPAPI. Локальные аккаунты и история автоматически на сервер не переносятся.
- Владелец группы может сразу добавить аккаунт Sombra по email. Участник получает доступ к текстовым и голосовым каналам. Вступление по коду также доступно.

## Проверка выпуска

Проверены сборка TypeScript/Vite и Rust, браузерный сценарий приглашения и переписки с двумя аккаунтами, вход в голосовую комнату и HTTPS-ответ рабочего API. Windows-установщик зарегистрировал версию 0.1.0 для текущего пользователя, после чего приложение запустилось.

TURN на рабочем сервере ещё не настроен. Передача звука между разными сетями и переход между двумя установленными версиями требуют отдельной проверки.

## Повторная сборка

Запустите `powershell -ExecutionPolicy Bypass -File Build-Release.ps1`. Установщик, подпись обновлятора и `latest.json` создаются в `release/<версия>/`. Перед новым выпуском обновите версии в `package.json`, `Cargo.toml`, `tauri.conf.json` и lock-файлах. Для подписи используйте действующий приватный ключ из исключённой из Git папки `release-secrets`. Порядок обновления сервера описан в [SOMBRA-SERVER.md](SOMBRA-SERVER.md).
