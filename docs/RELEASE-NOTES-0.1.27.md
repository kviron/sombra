# Sombra 0.1.27 — 22 ноября 2026

## Настройки

- Окно настроек стало матовым стеклом: панель просвечивает размытым чатом, подложка под окном больше не гасит фон наполовину.
- «Учётная запись» — одна карточка на всю ширину: обложка-баннер, аватар поверх неё, ник и описание. Раскладка карточки восстановлена после правок стилей.
- Кнопки над обложкой и у полей профиля переведены на общий компонент кнопок приложения: одинаковые высота, радиус, наведение, фокус и недоступное состояние. Иконочные кнопки перестали растягиваться по высоте.
- Журнал диагностики: шапка закреплена при прокрутке, кнопки выровнены с крестиком закрытия, заголовок и подзаголовок набраны как в остальных разделах.

## Журнал

- Новая кнопка «Очистить журнал» с подтверждением — удаляет только файлы диагностики, база и остальные данные остаются.
- Журнал теперь отличает тишину микрофона от потери пакетов: тишина определяется и по энергии, если WebView не отдаёт уровень звука.
- Если микрофон пропал (вынули наушники, отозвали доступ), в журнале появляется `voice_microphone: device_error` — раньше этот случай не фиксировался.

## Сеть и запросы

- Одинаковые одновременные чтения склеиваются в один запрос к серверу.
- Опрос состояния больше не наслаивается при медленной сети: раньше при зависшем ответе за двухсекундным тиком копились десятки копий.
- Пока окно скрыто, состояние не запрашивается; при возврате обновляется сразу.
- Музыка комнаты опрашивается реже, когда ничего не играет; сигнализация звонка — реже, пока в канале никого нет.

## Исправления

- Одна и та же запись больше не попадает в список дважды: повторяющиеся id в снимке состояния отбрасываются, из-за этого React ругался на неуникальные ключи.
- Голосовые уведомления и журнал после очистки продолжают писаться в новый файл.

## Внутреннее

- Фронтенд разложен по Feature-Sliced Design: `app → pages → features → entities → shared`, границы проверяет `npm run check:fsd`, карта слоёв — в `docs/FRONTEND-STRUCTURE.md`.
- Обновлены пути к встроенным ресурсам (тон уведомлений, звуки звонка) после переноса файлов; добавлены проверки путей в CI.
- Появились тесты на монитор транспорта (тишина, остановка пакетов, прямой и релейный путь) и на нормализацию состояния.
