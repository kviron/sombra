# Sombra 0.1.26

## Профиль

- «Учётная запись» — одна карточка на всю ширину: обложка-баннер, аватар поверх неё, ник и описание. Отдельная форма «Основная информация» с кнопкой сохранения убрана.
- Ник и описание правятся прямо в карточке: карандаш появляется при наведении, `Enter` сохраняет, `Escape` возвращает прежнее. Клик мимо не сохраняет — случайно половину имени не запишет.
- «Изменить аватар» открывает окно: картинка с загрузкой и удалением и выбор рамки — «Пламенный обод», «Слайм-питомец», «Без рамки».
- «Изменить обложку» открывает окно: картинка с загрузкой и удалением и анимация — «Сияние», «Бегун», «Без анимации».
- Полный каталог эффектов по-прежнему доступен кнопкой «Каталог эффектов» в обоих окнах.

## Обновления и выпуск

- Обновления теперь раздаются через GitHub Releases: `https://github.com/kviron/sombra/releases/latest/download/latest.json`. Манифест и подписанный установщик лежат рядом, подпись проверяется до установки.
- Прежний канал на `sombra.mi-nerva.ru` остаётся резервным адресом в клиенте.
- Выпуск собирает GitHub Actions: тег `vX.Y.Z` → черновик релиза → сборка и подпись NSIS → `latest.json` → публикация. Ручная раскладка на сервер больше не нужна.
- В CI добавлены проверки: тесты API и приложения, сборка фронтенда и сервера, сверка версии в четырёх файлах, валидность публичного ключа и скан дерева на секреты.

## Совместимость

- Сервер и API без изменений (0.1.25), старые клиенты продолжают работать.
- Клиентам 0.1.24–0.1.25 обновление приедет через мост на старом канале (`deploy/bridge-latest.sh`).
