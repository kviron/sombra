# Sombra 0.1.39

- Из голосовых комнат и настроек убраны индикаторы уровня микрофона. Паузы в разговоре больше не создают записи о тишине в диагностике. Микрофон остаётся включённым, пока вы в комнате, и его можно выключить вручную.
- Исправлено воспроизведение музыки при повторном входе в комнату. Если трек уже играет, плеер догружает его до текущей позиции и продолжает воспроизведение.
