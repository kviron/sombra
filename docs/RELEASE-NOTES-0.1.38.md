# Sombra 0.1.38

- К одному сообщению можно прикрепить до 10 изображений и файлов, добавить общую подпись и убрать отдельные вложения перед отправкой. Лимит каждого файла — 10 МиБ.
- Несколько изображений складываются в сетку с учётом пропорций. В просмотрщике Ctrl + колесо мыши меняет масштаб, а меню открывается через три точки или правую кнопку.
- При прокрутке чат повторно использует загруженные страницы истории. Для изображений заранее резервируется место, а неудачную загрузку можно повторить прямо в сообщении.
- Исправлен переход из ответа к исходному сообщению. Обновлены подсказки стикеров и диагностика голосовой связи.
