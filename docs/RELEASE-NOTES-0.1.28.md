# Sombra 0.1.28 — 22 ноября 2026

## Звонки: звук через сервер, как в Discord

Главное изменение: при наличии TURN-сервера звонок теперь идёт **через сервер Sombra**, а не
напрямую между участниками. Именно так устроен голос в Discord — у них нет прямых соединений
между клиентами, звук всегда ретранслирует голосовой сервер. Это убирает целый класс отказов:
прямой путь может «сойтись», но не пропускать звук в одну сторону, и тогда собеседник молчит
при чистом журнале с обеих сторон.

- Настройка: «Голос и видео → Соединение → Всегда через сервер», включена по умолчанию, если
  сервер выдал TURN.
- Настройка применяется к следующему подключающемуся участнику; текущие связи не рвутся.
- Если сервер не отдаёт TURN (например, локальная разработка), режим сам остаётся прямым —
  ничего не ломается.
- Одноразовые ключи TURN уже выдаются `voice_join`; в этом выпуске мы просто используем их
  всегда, а не как резерв.

Разбор протокола Discord и сверка с нашим стеком — в [VOICE-DISCORD-PARITY.md](VOICE-DISCORD-PARITY.md).
