# Sombra 0.1.34

- При сетевом обрыве P2P-звонок сначала пробует восстановить маршрут на существующем соединении. При неудаче пересоздаётся связь с затронутым участником.
- Клиент обновляет временные данные TURN во время длинного звонка.
- Обновлённые клиенты отправляют ICE-кандидаты группами. Старые клиенты по-прежнему получают одиночные сигналы.
- В пилотной комнате LiveKit звук передаётся через SFU.
