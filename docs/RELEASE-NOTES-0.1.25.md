# Sombra 0.1.25

- Аватары больше не пересылаются в каждом опросе состояния. Сервер отдаёт их отдельной операцией, клиент запоминает картинку по версии и загружает один раз. Ответ `state` уменьшился примерно с 1,2 МБ до размера переписки, поэтому исчезли тайм-ауты обновления и лишняя нагрузка на канал.
- Транспорт клиента сжимает ответ сервера, а nginx сжимает JSON: на слабом канале состояние и история загружаются заметно быстрее.
- У опроса состояния отдельный тайм-аут 30 секунд вместо общего 20: медленная сеть больше не срывает обновление на середине.
- Совместимость: сервер без поддержки `avatar_assets` продолжает отдавать аватары в ответе, а старый клиент с новым сервером видит прежние картинки.
