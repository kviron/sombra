## Sombra 0.1.30 — 22 ноября 2026

Честная диагностика микрофона, спокойное переподключение, релейный режим выключен по умолчанию.

Опубликованы [GitHub v0.1.30](https://github.com/kviron/sombra/releases/tag/v0.1.30) и зеркало на VPS. Установщик `Sombra_0.1.30_x64-setup.exe`, 11 595 623 байта, SHA-256 `6d4b819c9a628e184be01b0633faef08f08514b22299df3f44d149d114417a86`; копии на GitHub и VPS совпадают, подпись сходится с ключом `594FDFFC0E4DE222`. Предыдущий манифест — `/root/sombra-backups/release-manifest-20261122T194104Z/`.

Почему понадобилось: журнал молчал о микрофоне, потому что движок окна (WebView2/Chromium) не отдаёт `totalAudioEnergy` и `audioLevel` в `outbound-rtp` — проверено прямым замером на локальном соединении: в статистике только `packetsSent`, `bytesSent`, задержки. Прежняя проверка тишины опиралась на отсутствующие поля и не могла сработать. Теперь уровень измеряется через `AnalyserNode`, категории `mic_silent` / `mic_silent_recovered`.

Переподключение: `disconnected` ждёт 8 с (было 3 с), попыток три (было шесть), `failed` — 1,5 с. Прежние значения давали пересборку связи каждую минуту и провалы звука при каждой.

Релейный режим («Всегда через сервер») остался настройкой, но по умолчанию выключен: сервер — одна vCPU и 961 МБ памяти, занято 879 МБ, своп 405 из 512 МБ, iowait около 20 %. TURN остаётся запасным маршрутом ICE и включается сам, если прямой путь не складывается.

Проверки: `tsc`, `npm run lint` (0 ошибок), `check:fsd`, 92 теста, сборка. Живой звонок не проверялся — нужен второй участник с обновлённым клиентом.

## Проверка выпуска

Проверены сборка TypeScript/Vite и Rust, браузерный сценарий приглашения и переписки с двумя аккаунтами, вход в голосовую комнату и HTTPS-ответ рабочего API. Windows-установщик зарегистрировал версию 0.1.0 для текущего пользователя, после чего приложение запустилось.

## Повторная сборка

Запустите `powershell -ExecutionPolicy Bypass -File Build-Release.ps1`. Установщик, подпись обновлятора и `latest.json` создаются в `release/<версия>/`. Перед новым выпуском обновите версии в `package.json`, `Cargo.toml`, `tauri.conf.json` и lock-файлах. Для подписи используйте действующий приватный ключ из исключённой из Git папки `release-secrets`. Порядок обновления сервера описан в [SOMBRA-SERVER.md](SOMBRA-SERVER.md).
