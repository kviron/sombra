# Название для готового приложения

**Юно (YUNO)** — основной вариант: короткое и мягкое название, которое легко произнести: «Зайди в Юно».

Запрос касается только подбора названия. Приложение уже существует; переименование и изменение интерфейса не требуются. Вариант пока не утверждён.

# Варианты названия

## Новое направление: простое, мягкое звучание

Короткие названия в два слога, которые удобно произнести в разговоре: «Зайди в Юно», «Созвонимся в Руни». Подборка строится на звучании и лёгкости произношения, без мифологии и эпического настроения.

1. **YUNO — Юно** — плавное, дружелюбное; мой основной вариант для приложения общения.
2. **RUNI — Руни** — живое и уютное, легко запомнить на слух.
3. **LUMO — Лумо** — мягкое и округлое, с тёплым настроением.
4. **TAVI — Тави** — лёгкое, чёткое, немного игривое.
5. **NOLI — Ноли** — спокойное и мелодичное.
6. **RILO — Рило** — короткое, ритмичное, бодрое.
7. **SAVI — Сави** — мягкое начало и звонкое окончание.
8. **MILO — Мило** — тёплое и знакомое русскому уху.
9. **TIMO — Тимо** — простое, дружеское, почти как имя приятеля.
10. **LAVI — Лави** — лёгкое и певучее.
11. **NORI — Нори** — лаконичное и спокойное.
12. **ZUNO — Зуно** — более звонкое и энергичное.

Короткий список для выбора: **Юно, Руни, Лумо, Тави**. Если выбирать одно по звучанию — **Юно**.
Это подборка идей; название в приложении меняется после выбора. Совпадения с существующими брендами и доступность доменов не проверялись.

## 20 коротких сочетаний имён богов

Вымышленные названия из частей имён разных культур — не исторические имена богов.
Все варианты состоят из 4–6 латинских букв; рядом дано русское прочтение.

1. **RAKI — Раки** — Ра + Локи (Египет + Скандинавия).
2. **ODRA — Одра** — Один + Ра (Скандинавия + Египет).
3. **ANOR — Анор** — Анубис + Тор (Египет + Скандинавия).
4. **LORES — Лорес** — Локи + Арес (Скандинавия + Греция).
5. **FRENI — Френи** — Фрейя + Агни (Скандинавия + Индия).
6. **VESRA — Весра** — Веста + Ра (Рим + Египет).
7. **TORIS — Торис** — Тор + Исида (Скандинавия + Египет).
8. **ISOD — Исод** — Исида + Один (Египет + Скандинавия).
9. **SETRA — Сетра** — Сет + Индра (Египет + Индия).
10. **INORA — Инора** — Индра + Аврора (Индия + Рим).
11. **AGNOR — Агнор** — Агни + Тор (Индия + Скандинавия).
12. **SHIRA — Шира** — Шива + Ра (Индия + Египет).
13. **SHILOK — Шилок** — Шива + Локи (Индия + Скандинавия).
14. **VELOR — Велор** — Велес + Тор (славянская + скандинавская традиции).
15. **PERES — Перес** — Перун + Арес (славянская + греческая традиции).
16. **HERIS — Герис** — Гера + Исида (Греция + Египет).
17. **JUNRA — Юнра** — Юнона + Ра (Рим + Египет).
18. **NEIKI — Нейки** — Нейт + Локи (Египет + Скандинавия).
19. **OSIN — Осин** — Осирис + Один (Египет + Скандинавия).
20. **APOR — Апор** — Аполлон + Тор (Греция + Скандинавия).

Для приложения общения особенно выделяются **Велор, Инора, Анор, Торис и Шира**: короткие и легко произносятся.
Это варианты для выбора; текущее название приложения пока сохраняется.

## Предыдущая подборка

10 вариантов для приложения игрового общения — без ограничения на первую букву.
Это предложения для выбора, а не утверждённое переименование.

1. **NEXORA — Нексора.** Футуристично и звучно; ассоциация с точкой встречи команды.
2. **ONYX — Оникс.** Короткое, твёрдое название под тёмный интерфейс.
3. **RIFT — Рифт.** Разлом или портал в пространство своей команды.
4. **AEGIS — Эгида.** Защита, щит и чувство единства отряда.
5. **RELAY — Релей.** Передача голоса и постоянная связь между игроками.
6. **CITADEL — Цитадель.** Собственная крепость для друзей и сообщества.
7. **PULSAR — Пульсар.** Энергия, сигнал и общий ритм команды.
8. **EMBER — Эмбер.** Искра и уютное место для разговоров после игры.
9. **RALLY — Ралли.** Сбор команды перед следующим матчем.
10. **NOX — Нокс.** Лаконичное ночное название для тёмной игровой эстетики.

Для более пафосного звучания: NEXORA, AEGIS, CITADEL.
Для короткого и запоминающегося: ONYX, RIFT, NOX.

Понравившийся угловатый логотип можно оставить как самостоятельную эмблему: он не обязан совпадать с первой буквой названия.
Доступность названий, доменов и товарных знаков пока не проверялась.
