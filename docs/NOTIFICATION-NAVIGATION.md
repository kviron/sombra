# Переход из уведомления в переписку

Уведомление несёт типизированную цель `{account, channel, message}`. URL, команды, JavaScript и путь к файлу не используются; поля ограничены ID, без произвольных дополнительных свойств.

- Нажатие на тело уведомления открывает соответствующий ЛС/групповой ЛС/канал, закрывает настройки и перекрывающие диалоги. Сообщение прокручивается и подсвечивается, если оно ещё есть в доступной истории.
- Крестик только закрывает уведомление. Кнопка открытия доступна с клавиатуры.
- В Windows popup передаёт цель нативной команде. Основное окно показывается, разворачивается из свёрнутого состояния и запрашивает фокус. WinRT fallback использует собственный обработчик Activated с захваченной типизированной целью.
- Цель хранится до готовности основного frontend и атомарно забирается один раз. Событие служит сигналом, а не вторым независимым источником перехода.
- До перехода запрашивается свежий авторизованный state, проверяются аккаунт и членство в диалоге/группе. Выход, смена аккаунта и новый клик отменяют старую асинхронную активацию. Нельзя автоматически вступить в чужую группу или запустить звонок нажатием на уведомление.
- Несколько чатов получают отдельные уведомления с собственными целями вместо общей неоднозначной сводки; звук один на пачку.

## Граница поддержки

Это активация **работающего процесса**, в том числе свёрнутого/скрытого в трей окна. Приложение сейчас получает сообщения опросом, а не отдельной системной push-службой. Публичная схема `sombra://`, регистрация протокола и запуск после полного завершения процесса здесь не добавляются. Не следует заявлять cold-start activation по сохранённому системному уведомлению.

TypeScript/Vite, тесты DTO/маршрутов и компиляция Windows-ветки проверяются отдельно от физического нажатия Windows toast. Браузерные CDP-сценарии проверяют настоящие React DOM-клики, а нативный IPC подменяют на его границе; это не эмуляция доказанного OS foreground permission или холодного запуска.

Изменение клиентское; backend, Hermes и production-данные не меняются. Для установленного клиента потребуется новый установщик/обновление; опубликованная 0.1.17 автоматически от правки исходников не меняется.
