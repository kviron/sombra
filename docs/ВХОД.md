# Как войти в Mines

1. Откройте экран «Войти».
2. В поле «Электронная почта» введите `owner@mines.local`.
3. Пароль первого аккаунта указан в файле `data/FIRST-USER.txt` рядом со строкой `Password:`. Скопируйте только сам пароль, без пробелов и названия строки.
4. Нажмите «Войти».

Пароль создаётся при первом запуске и отличается для каждой новой базы. Если настроена папка MINES_DATA_DIR, ищите FIRST-USER.txt в ней.

Для отдельного аккаунта нажмите «Создать аккаунт» и задайте свои почту и пароль.
