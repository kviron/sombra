# Sombra 0.1.33 — 23 ноября 2026

Архитектура FSD, Tailwind вместо локального CSS и история сообщений страницами.

## Архитектура

- Логика страниц и фич вынесена в `model` на Zustand: чат, карточка сообщения, профиль,
  настройки аккаунта, голосовая комната, боты, вложения, стикеры, материалы и уведомления.
  Компоненты снова только показывают данные и вызывают готовые действия.
- `account-settings` разбит на шесть фич; сервис аккаунта переехал в `entities/account`.
- Раскладка окна — в `shared/layouts`, правило «Tauri только через `shared/api/tauri`»
  проверяется на уровне кода.
- 337 тестов фронтенда: правила ботов, друзей, истории, сообщений, профиля и звонков
  проверяются отдельно от React.

## Tailwind

- Пилот в `entities/message`, затем все срезы: вложения, текст, упоминания, чат,
  лента сообщений, профиль, диалоги, настройки, голосовая комната, боты, уведомления,
  обновления и общие поверхности.
- В `pages/chat` CSS уменьшился с 1871 до 985 строк (−886). В CSS осталось только
  невыразимое: `@keyframes`, `@media`, `:has()`, `::placeholder`, переопределения общих
  компонентов, hover/focus/disabled и правила, которые проигрывают утилитам по
  специфичности из-за нелейерных `glass.css`/`chat-extras.css`/`user.css`.
- Матовые поверхности и диалоги переведены на общие токены `--surface-*` и `.surface-matte`.
- Регрессии проверены двумя сборками в headless Chrome: 9 сцен (8,5 млн пикселей),
  0 отличий; вычисленные стили ~50 селекторов в каждой сцене совпали.
- Весь код отформатирован Prettier; `check:fsd` проходит.

## История сообщений

- Серверная часть умеет отдавать историю канала страницами (`messages_page`) и сообщает
  `historyTruncated`; клиент подгружает старые страницы без скачка прокрутки, автоматически
  у первого сообщения и по кнопке «Показать более ранние».
- Догрузка идемпотентна: повторный запрос не дублирует сообщения, устаревший курсор
  начинает страницу заново.

## Мелочи

- Картинки в переписке: высота по пропорциям, потолок 420 px, контекстное меню
  «Скопировать» и «Скачать».
- Журнал диагностики принимает все категории клиента.
- Проверки: `tsc`, `npm run lint` (0 ошибок), `check:fsd`, 337 тестов, Vite-сборка.

Серверный бинарник в этот выпуск не входит: действующий backend остаётся прежним,
страничная история включится после его обновления. Клиент на старом сервере работает
как раньше.
