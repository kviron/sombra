# Sombra 0.1.16 — материалы переписки и аккуратные настройки

- В правой части шапки чата появилась кнопка открытия панели материалов: фото, видео, файлы, аудио и ссылки со счётчиками.
- Панель работает отдельно для текущей личной/групповой переписки, текстового или голосового канала группы. Поиск находит название файла, ссылку, текст сообщения или автора. Переход в другой чат сбрасывает категорию и запрос.
- Фото собраны в сетку по месяцам; доступен увеличенный просмотр. Вложения скачиваются через существующий авторизованный механизм. Ссылки открываются безопасно, без загрузки сторонних превью и без передачи истории сторонним сайтам.
- Кнопка у материала переводит к исходному сообщению, очищает поиск сообщений и подсвечивает результат. Недоступные старые вложения остаются в истории с соответствующей отметкой.
- История материалов показывается порциями: первые 60 элементов, затем «Показать ещё». Счётчики и поиск работают по всей доступной истории.
- На узких окнах панель не закрывает поле ввода, включая многострочный черновик. Список участников и материалы не накладываются друг на друга.
- Все разделы настроек получили компактную согласованную компоновку: поля и кнопки высотой 36px, ровные подписи, 44px строки форм и единый шаг отступов 8px. Уменьшена ширина навигации и убраны лишние отступы/влияние старых общих CSS-правил.
- Упорядочены настройки профиля, безопасности, сеансов, голоса/видео, уведомлений, обновлений, стикеров и групповых подключений. Сохранены фирменные цвета, матовое стекло и существующая функциональность.

Изменения клиентские: API и данные на сервере не меняются, звонки не требуют перезапуска серверных сервисов.
